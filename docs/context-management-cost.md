# Hemlock 上下文管理策略：成本优势对比

> 同一个渗透测试任务，用同一个大模型，**Hemlock 的整体上下文管理策略**
> 让输入成本降到普通 Agent 的 **约 1/169**。
> 这不是某一个技巧，而是「渐进式披露 + 前缀缓存稳定 + 增量控制 + 渐进压缩」
> 四层策略叠加的结果。

## 口径说明

- **任务**：同一个渗透测试任务，60 轮对话（侦察 → 深测 → 验证 → 报告全流程）
- **模型**：DeepSeek-V4-Flash（1M 上下文，平峰价：未命中输入 **1 元/M**，缓存命中输入 **0.02 元/M**，即命中价 = 未命中价 1/50）
- **Token 估算**：`len/3.5`（中英混合，±20% 误差可接受）
- 只对比**输入**成本（输出 token 两边相同，不影响结论）

> 价格口径与 DeepSeek 官方 2026-08 公开价一致。DeepSeek 已预告近期大幅涨价，
> 命中 / 未命中价差只会拉大，缓存优势随之更值钱。

## 完整总账：同一任务，两套上下文策略

| | 普通 Agent 默认做法 | Hemlock 整体策略 |
|---|---|---|
| **system** | 99 个技能**全文** 308,848 tok + 策略 + 43 个工具全量 | 稳定段 2,406 + 技能**索引** 3,468 + 记忆快照（前缀命中 1/50） |
| **工具注入** | 43 个全量注入（6,793 tok） | 核心 29 个 + `load_tools`（5,258 tok），discovery/file 14 个按需加载 |
| **历史段** | 每轮全量重发、无前缀稳定 → 未命中全价 | 纯追加，前缀逐字节稳定 → 缓存命中价 |
| **工具结果** | 全量回流（单轮约 4,000 tok） | 截断 headers≤1KB / body≤3KB + 蒸馏（单轮约 1,500 tok） |
| **超窗口时** | 粗暴丢弃最早消息（丢上下文） | AutoCompact 三层渐进压缩 + 分界线固化，不丢上下文 |
| **60 轮累计输入** | **≈ 26.4 元** | **≈ 0.16 元** |

**60 轮累计：26.4 元 → 0.16 元，省约 169 倍（成本只剩 0.6%）。**

## 这不是单一技巧：四层策略组合

| 层级 | 策略 | 60 轮省下 | 占省下总额 |
|---|---|---|---|
| **L1 渐进式披露 + 按需加载** | 技能 / 记忆只注入「名称 + 描述」索引，完整内容按需读取（`get_memory` / `invoke_skill`）；发现 / 文件类工具按组 `load_tools` 加载 | **18.3 元** | 69.5% |
| **L2 缓存前缀稳定** | system 稳定段逐字节不变、历史纯追加、记忆快照对话开始固化、技能 / 记忆 / MCP 确定性排序——让自动前缀缓存吃得上 | **7.7 元** | 29.0% |
| **L3 输出截断 + 蒸馏** | HTTP 输出截断（headers≤1KB / body≤3KB），>6000 字符消息蒸馏，控制单轮增量 | **0.24 元** | 0.9% |
| **L4 渐进压缩** | Session Memory → LLM AutoCompact → 确定性压缩，熔断自动回退 | 60 轮内不触发，长任务兜底 | — |

### 关键洞察

- **L1 最大**：普通 Agent 把技能知识库全文塞 system 是最大坑。99 个技能全文
  **308,848 tokens**，在 128K 窗口的模型上**根本跑不了**；即便 1M 窗口硬塞，
  光 system 每轮就约 0.32 元。Hemlock 的索引 + 按需加载让它永远只付约 3.5K。
- **L2 是设计产物**：前缀稳定不是免费的——稳定段拆分、纯追加不重算、快照固化、
  MCP 排序，都是为了**让自动前缀缓存实际命中**。普通 Agent 若每轮重组历史 / 热窗口
  滑动截取，缓存永远命中不了。
- **L3 是前两层的前提**：不截断工具结果，历史每轮 +4K，任务越长越早爆窗口。

## 实测锚点（token 估算，len/3.5）

| 项 | tokens |
|---|---|
| 99 个技能全文 | 308,848 |
| 技能索引（注入的） | 3,468 |
| 稳定段（SYSTEM_PROMPT + AUTO_PENTEST） | 2,406 |
| 43 个工具全量定义 | 6,793 |
| 核心工具 + load_tools | 5,258 |
| 单轮：普通 Agent system | ~318K（全价） |
| 单轮：Hemlock 固定前缀命中后 | ~227（命中价）+ 本轮新增 |

## 长任务表现

- **普通 Agent**：超过窗口粗暴丢最早消息 → Agent 忘记早期发现，结论失真
- **Hemlock**：AutoCompact 三层渐进压缩（Session Memory 免费 → LLM 摘要 → 确定性兜底）
  + v0.4.3 分界线机制（压缩结果固化到任务轨迹，恢复线性展开不重算），
  长任务不爆上下文、不丢记忆

## 结论

Hemlock 的成本优势是**整套上下文管理策略组合出来的**：
渐进式披露控制注入量 → 前缀稳定吃满缓存价 → 截断 / 蒸馏控制增量 → 渐进压缩兜底。
每一条都单独看是"省一点"，组合起来是数量级的差距。
