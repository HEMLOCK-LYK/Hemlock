# Screenshots

此目录用于存放 Hemlock 界面截图。

## 建议截图清单

| 文件名 | 内容 |
|--------|------|
| `main.png` | 主界面总览 |
| `agent.png` | Agent 对话界面（含思考链、工具调用） |
| `packet.png` | 数据包查看界面 |
| `traffic.png` | 流量列表界面 |
| `multi-agent.png` | 多 Agent 协作界面 |
| `theme-dark.png` | 暗色主题界面 |
| `theme-light.png` | 亮色主题界面 |
| `settings.png` | 设置 / LLM Provider 管理界面 |

## 截图规范

- 分辨率：1920x1080 或更高
- 格式：PNG
- 内容中不要包含真实目标地址或敏感信息
